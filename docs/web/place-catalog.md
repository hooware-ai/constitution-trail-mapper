## Source decisions and limits

- Tipton’s street number is **2201** on the [managing City’s current listing](https://www.bloomingtonparks.org/Home/Components/FacilityDirectory/FacilityDirectory/98/825?npage=4). The county point says 2210; the catalog uses the City’s address and the county’s explicitly named north-entrance point. The City page blocked direct retrieval, so its address was checked in the current official search-index result and corroborated by the [local visitors bureau](https://www.visitbn.org/locations/tipton-park-north-pavilion/).
- Fairview uses the Town’s own facility marker, not its page’s unrelated default US map center or a different county park-center marker. The Town reports marker accuracy 100 without a stated unit; do not infer pedestrian-entrance accuracy.
- These are representative facility locations, not verified pedestrian entrances or guarantees of connected public walking access. The north-entrance name is the source’s label, not a new field survey. Keep estimated access visible and block navigation where the routing engine cannot establish a safe mapped connection. Do not move a place onto a nearby route vertex to suppress that safeguard.
- Removed the guessed Vernon Avenue and GE Road trail-crossing entries: no authoritative named point was verified for those exact catalog locations. A user can still select a point on the map.
- Public availability of these factual point records is not a blanket license for republishing the source GIS databases or facility-page material. No source page body, imagery, or park polygon is bundled. This small factual catalog does not resolve the broader public-release gate in [data-rights.md](data-rights.md); the build remains for local review only.
